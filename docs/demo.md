# Demo

The demo page renders the full set of HTML elements with every Bullframe CSS build variant. Use the selector at the top to switch between the light, dark, system-default, classless, utilities-only, and modern builds.

::: tip
The demo is served as a standalone page so it can use its own full HTML document and body classes without conflicting with the VitePress documentation styles.
:::

<a href="/demo/index.html" target="_blank" rel="noopener" class="VPButton medium brand" style="margin-top: 1rem;">Open interactive demo</a>

## What to check

- **All eight builds**: light, dark, system-default, classless, classless-dark, classless-system-default, utilities-only, and modern.
- **Responsive typography**: resize the viewport to see the fluid type scale.
- **Form elements**: radios, checkboxes, ranges, selects, validation states.
- **Accessibility**: skip link, focus styles, reduced-motion support.
- **Dark mode**: switch your OS preference while using the system-default builds.
