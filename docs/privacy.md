# Privacy

Last updated: 2026-10-15

This notice covers the Bullframe CSS documentation site at `bullframecss.marcopontili.com`. The framework itself is a set of CSS files and processes no personal data.

## Controller

Marco Pontili.\
Contact: [marcopontili.com/contact](https://marcopontili.com/contact)

## Analytics: self-hosted Matomo

- Page views and outbound link clicks are measured with a self-hosted Matomo installation at `mt.marcopontili.com`, run by the controller on its own server in the European Union.
- Matomo runs cookieless: no cookies or similar identifiers are stored on your device.
- IP addresses are anonymised before storage.
- If your browser sends a Do Not Track signal, no analytics request is sent.
- Data processed: anonymised IP address, page URL, referrer, browser and device type, and time of visit.
- No profiles are built and the data is not shared with third parties.

Legal basis: Art. 6(1)(f) GDPR, the legitimate interest in privacy-friendly, aggregate traffic measurement.

## Hosting

The site is hosted by Netsons S.r.l. (Italy), acting as processor. The host processes server log data, including IP addresses, as needed to deliver the site and keep it secure. Legal basis: Art. 6(1)(f) GDPR. Place of processing: European Union (Italy). Requests pass through Cloudflare for transport security and caching; Cloudflare web analytics is not used.

## Retention

Analytics and log data are kept only as long as needed for the purposes above, then deleted.

## Cookies and local storage

No cookies are set. The site stores your light or dark theme choice in your browser's local storage so it survives a reload; that value never leaves your device. No consent banner is shown because none of this requires consent.

## Your rights

You can request access to, correction, deletion, restriction, or portability of your data, and object to processing, through the contact page above. You may lodge a complaint with the data protection authority where you live or work. The same rights and the same contact route apply wherever you are in the world.
