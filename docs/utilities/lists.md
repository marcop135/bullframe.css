# List utilities

`.bf-list-unstyled` removes margins, padding and markers from a `ul`, `ol` or `dd`, and from lists nested inside it.

```html
<ul class="bf-list-unstyled">
  <li>Item one</li>
  <li>Item two</li>
  <li>Item three</li>
</ul>
```

Element list styles are on the [Typography](/typography#lists) page.
