Installing Fieldnote

Fieldnote runs as a single binary. This page covers install, first run and the two configuration files it reads.

On this page

  1. Requirements
  2. Install
  3. Configuration

Requirements

Node 20 or newer, and 200 MB of free disk space.

Install

npm install --global fieldnote
fieldnote init

The init step writes fieldnote.json into the current directory and never overwrites an existing file.

Configuration

Configuration files, in load order
File Scope Wins
~/.fieldnote.json User No
fieldnote.json Project Yes

A missing configuration file is not an error. Fieldnote falls back to its defaults and says so on first run.
